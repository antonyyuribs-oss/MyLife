Segurança e portabilidade

Dados e backup

Suas notas são suas

O MyLife armazena notas e fotografias neste dispositivo e navegador, sem conta e sem servidor. O backup JSON também inclui as imagens e pode ser maior. O Markdown é próprio para compartilhar texto; a exportação Markdown de uma nota pode incluir imagens incorporadas e gerar arquivos grandes. Exporte-o regularmente: apagar os dados do site, trocar de aparelho ou limpar o navegador pode eliminar as notas locais. Backups com mídia podem ficar grandes.

Trazer notas do iPhone

Importe diretamente arquivos Markdown (.md/.markdown) exportados do Notas do iPhone ou arquivos JSON do MyLife, pelo mesmo botão. Você pode selecionar várias notas de uma vez. O Markdown é convertido em blocos editáveis: títulos, texto formatado, listas, checklists, tabelas, citações, código e links. Para fotografias e outros anexos, o JSON é o formato mais completo. Também é possível adicionar fotos e documentos pelo editor.

As imagens ficam guardadas neste dispositivo, junto com as notas. A exportação JSON inclui as fotografias. O MyLife não acessa automaticamente o Notas do iPhone ou o iCloud. Imagens apenas referenciadas no Markdown não são baixadas: salve-as em Fotos/Arquivos para adicioná-las pelo editor. Imagens incorporadas como dados no Markdown podem ser importadas. Recursos exclusivos da Apple (colaboração, notas protegidas, transcrição automática, escrita à mão editável e reconhecimento de imagens) não são importados como funções nativas.
